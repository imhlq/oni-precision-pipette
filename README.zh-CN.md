# 又一款精准滴管（YAPP）

在《缺氧》的地图格和管道之间定量取放液体与气体。例如，从水管取一管水，切回地图，在液封上方滴下。只向选中的格子投放；目标无效时，样本留在管中。

[下载 v0.15.0 安装包](https://github.com/imhlq/oni-yet-another-precision-pipette/releases/download/v0.15.0/YAPP-install.zip) · [English](README.md) · [MIT 许可证](LICENSE)

仓库当前版本使用下述新名称和科技要求；上方 v0.15.0 安装包为此前发布的版本。

## 安装

适用于 U60，最低游戏构建号为 **763796**。退出游戏，解压安装包，将 **OniPrecision** 文件夹复制到游戏用户数据目录的 `mods/Local`。Windows 通常为 `文档\Klei\OxygenNotIncluded\mods\Local`。在模组菜单启用 **又一款精准滴管（YAPP）**，按提示重启。

## 使用

从开局起，指向液体或气体并按住**左 Alt** 即可使用移液器或移气管。光标旁的原生标签显示目标格信息，管中样本另行显示元素、质量和温度。

| 操作 | 效果 |
| --- | --- |
| 按住左 Alt | 先指向液体或气体，再按下左 Alt 临时选管。移动鼠标保持管型；管中有样本时，松开 Alt 可继续取放。空管且取放结束后自动退回原工具。 |
| 指向复制人时按住左 Alt | 左键长按 0.45 秒抓住目标，保持左键并移动鼠标缓慢拖动；墙壁会挡住移动，松开左键释放。 |
| 长按左键 / 右键 0.65 秒 | 取样 / 投放，提前松开可取消。管未满时可继续吸取同种元素。 |
| 点击挡位或 左 Alt + 滚轮 | 切换 **10 微克、10 毫克、10 克、10 千克**。也可在右侧输入 1–1000 ，点击数值旁的单位即可轮换。两支管的设置分别随殖民地保存。 |
| Tab / 反引号键 | 切换对应管道视图 / 返回地图。取样后也可切换。 |
| Esc | 退出工具，保留管中样本。 |

开启「仅允许同类目标」可限定向空目标或同种元素投放；关闭后可向空气滴液。默认保持样本原温，完成温度调节研究（`TemperatureModulation`）后，不超过 20 g 的样本可指定投放温度。可在「模组」页面的 YAPP 条目开启「解除温控限重」（默认关闭）。

## v0.15.0 实测

在 Moono、U60 构建 **764025** 中，分别向装有氧气、水、黏性凝胶的封闭单格连续投放 **64 次**，每次 **15.625 克**。三组均从 **1 千克**增至 **2 千克**。共 192 次，每次格内质量都符合预期，管中余量均为零。完全重启游戏并读档后，移气管 **35 毫克**、移液器 **15 千克**的设置也分别恢复。

暂停时连续取放、地图与管道双向转移，以及带样本读档仍待实机验证。若游戏提示转移结果无法核对，请退出且不保存，再读取操作前备份。
