# 精准移气移液：U60 本地稳定性候选

**本包是 v0.2.2-u60-moono-local，目标为 U60 正式版。Moono 差异和验收见 [README-Moono.zh-CN.md](README-Moono.zh-CN.md)。**

**GitHub 测试分支，未出正式 Release，未在真实游戏内验证。main 和 v0.2.0 不变。** 源码构建见 [README](README.md)，独立地图诊断见 [采样器说明](diagnostics/map-probe/README.md)。

**本版禁用所有地图取样、投放和退回！地图只可查看。不能直接向保鲜格注入微克气体、深冷食物格或制作地图液锁。** 地图和管道仍是独立空间；任一地图端点的新转移都会在扣取前拒绝。已删除异步 ConsumeMass/EmitMass 调用：成功标志无法证明准确落点、质量或未改投；丢失回调不能当作失败，更不能猜测后退款、重试或解锁。

同一面板保留气管→气管、液管→液管。气体 10 µg–1 kg，液体 1 mg–10 kg；单精度无法精确记账则拒绝。温控研究解锁后允许单次最多 20 g 变温，并拒绝相变温度。不修改食物腐败机制，不保证普通排气口准确投放地图剂量。

## 安装与使用

退出游戏并备份独立测试存档；仅启用一个 OniPrecision。解压本地安装 ZIP，将 OniPrecision 文件夹放进用户数据目录的 mods/Local，替换旧本地文件。不要在旧版仍等待回调时升级。未知的旧转移无法通过升级重建。

默认选择管道。选好起点、目标、剂量，解除暂停后执行一次。满管、异种元素、不同病菌种类、无法核对的数值均拒绝，不覆盖、不改投邻格。变温需要 TemperatureModulation 研究。缓冲可选择所选管道投放、按原温投放，或退回经过验证的原管道。

## 缓冲与异常

- 核对管道实际扣取、接收的质量和病菌。可确认的部分接收会保留准确余量，病菌使用真实差值，不按比例猜测。确认未发生变化的拒绝可重试。
- v0.2 空缓冲遗留的病菌/温度字段会清理。非空旧缓冲原样保留，可明确选择兼容管道按原温投放；旧版没有记录原世界身份，**禁止自动退回旧原点**。新样本会核对原世界。地图退回永远禁用。异常非空旧数据保留，但禁止转移。
- 原生调用异常或账目无法确认时进入隔离状态，禁止重试、退款或自动解除。保存不确定标记和请求上下文只是防止误重试，**不表示缓冲质量已被证明安全独占**。恢复方法：不要保存，退出并读取操作前备份；会失去之后的进度。
- 正常转移、已确认的缓冲不阻止保存。隔离时使用 Game.CanSave，并在可用时使用 ClusterManager 的原生保存阻止器。U60 beta 参考程序集缺少后者。**自动保存、保存并退出的完整覆盖未实测，不能保证每条保存路径均被阻止。** 没有会向保存管线抛异常的序列化补丁。隔离后不要保存或覆盖备份；若其他保存路径仍写入隔离状态，重新载入也不会允许再次投放。
- 必需挂钩缺失或安装失败会禁用转移，不再无条件 PatchAll。
