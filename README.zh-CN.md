# Yet Another Precision Pipette (YAPP)

在《缺氧》中定量移动液体和气体。可以从地图格或管道取样，再选择投放位置。例如，要让一滴水从空中落下，可以先取水，关闭「仅允许同类目标」，然后在落点上方的空气格长按右键。

**v0.14.2** 适用于 U60，最低游戏构建号为 763796。[English](README.md) · [Moono 兼容性说明](README-Moono.zh-CN.md) · [MIT 许可证](LICENSE)

## 取样与投放

在「水管」菜单选择「取液器」，或在「通风」菜单选择「取气管」。本测试版自动开放工具。右侧参数栏可输入 1–1000 的装填上限，单位可选微克、毫克、克或千克。滑条按 1、5、10、15……调节。

| 操作 | 效果 |
| --- | --- |
| 左键长按 0.65 秒 | 从高亮格取样。管未满时，可继续吸取同一种元素。 |
| 右键长按 0.65 秒 | 向有效目标投放样本。提前松开可取消。 |
| Ctrl + 滚轮 | 循环切换 10 微克、10 毫克、10 克、10 千克四个预设。 |
| Tab | 在地图与对应管道视图间切换。取样后也可切换，再选择投放位置。 |
| 反引号键 | 返回地图视图。 |
| Esc | 退出工具并保留管中样本。 |

光标旁的原生标签显示目标格的信息，样本标签显示管内物质。开启「仅允许同类目标」后，只能向空目标或相同元素投放。默认保持原温；符合条件且不超过 20 克的样本可以指定投放温度。

## 安装

1. 按[源码构建步骤](README.md#build-and-install)生成安装包，或直接使用已有的 `YAPP-install.zip`。
2. 退出游戏并解压，将其中的 `OniPrecision` 文件夹复制到游戏用户数据目录下的 `mods/Local`。Windows 通常位于 `文档\Klei\OxygenNotIncluded\mods\Local`。打开 `OniPrecision` 应能直接看到 DLL 和两个 YAML 文件。
3. 在游戏模组菜单启用 **Yet Another Precision Pipette (YAPP)**，按提示重启，首次使用时载入殖民地副本。

## 实测与存档

在 Moono、游戏构建 764025 上，已成功载入殖民地副本。连续 15 轮切换液体与气体管道视图后，回到地图仍能看到原生氧气标签中的名称、类型、质量和温度。**暂停时连续取放、地图与管道双向转移，以及带样本存读档仍待实机验证。**

管道只接收部分样本时，工具根据实际接收的质量和病菌数保留余量。如果游戏回执无法核对，工具会锁定转移。此时应退出且不保存，再读取操作前备份。自动保存和「保存并退出」的完整保护仍待实测。从 v0.2 升级前，请先完成进行中的转移并保留独立备份。
